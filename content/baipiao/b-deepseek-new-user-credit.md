## 教程

### 访问开放平台

打开 platform.deepseek.com，点击右上角「登录/注册」。

### 注册并验证

使用手机号注册，完成短信验证码校验。

### 查看赠送额度

登录后进入「用量信息」页面，可以看到赠送额度的余额与到期时间。

### 创建 API Key

在「API Keys」页面点「创建」，复制保存好密钥（只显示一次）。
